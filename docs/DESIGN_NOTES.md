# Дизайн-заметки: перевод интерфейса на Carbon

Рабочие заметки к редизайну по `DESIGN.md` (Carbon / IBM) и скиллу
`.claude/skills/frontend-design`. Что сделано, какие решения приняты,
что осталось — для следующих проходов.

## Система

**Предмет.** Платформа Наблюдательного совета АО. Аудитория — члены
совета (включая независимых иностранных), корпсекретарь, правление.
Главная работа интерфейса: без двусмысленности показать, когда
заседание, что на голосовании, что подписано. Регистр — архив и
протокол, не «продукт».

**Токены** (`src/index.css`, `:root`):

| Роль | Значение |
|---|---|
| Текст | `#161616` ink · `#525252` muted · `#8d8d8d` subtle |
| Поверхности | `#ffffff` canvas · `#f4f4f4` surface / фон страницы · `#e0e0e0` hairline |
| Акцент (единственный) | `#0f62fe`, hover `#0050e6`, active `#002d9c`, tint `#edf5ff` |
| Статусы | success `#24a148`/`#defbe6` · warning `#f1c21b`/`#fcf4d6`, текст `#684e00` · error `#da1e28`/`#fff1f1` |
| Шрифт | IBM Plex Sans 300/400/600; body 14px, tracking 0.16px |
| Скругления | 0 везде, кроме аватаров (круг) |
| Тени | только оверлеи: `--shadow-overlay` |

**Каркас.** Carbon UI Shell: тёмная шапка 48px (`#161616`) — единственная
инвертированная поверхность; белая навигация 256px с 3px синей рейкой у
активного пункта, группы разделены хайрлайнами; контент на `#f4f4f4`
с белыми плитками в хайрлайн-обводке.

**Один смелый элемент.** На главной дата ближайшего заседания — число
60px весом 300. Левая 3px рейка плитки кодирует состояние: зелёная —
идёт, жёлтая — скоро, синяя — запланировано, серая — завершено, hairline —
нет заседания.

## Что сделано (сентябрь 2026)

- `index.css` — новая система токенов, Plex Sans, фокус Carbon (2px, offset −2),
  кнопки `.btn-*` 12×16 square, инпуты с нижней линией, теги square.
- `ui.tsx` — Card/StatusBadge/RoleBadge/EmptyState/PageHeader/LoadingScreen.
- `Layout.tsx` + `Sidebar.tsx` — новый шелл; язык, поиск, уведомления, аватар
  в шапке; в навигации только пункты (без логотипа-щита).
- `LoginPage.tsx` — сплит-экран, лейблы над полями, уведомления с левой рейкой,
  раскладка в CSS (`.login-*`) со стеком под 768px.
- `DashboardPage.tsx` — герой с датой, строки вместо «карточек в карточках».
- Массовый проход по 37 файлам (`scripts` в истории коммита): Tailwind-палитра →
  Carbon (1738 замен), скругления → 0 (433), тени (37), капс-лейблы (33),
  эмодзи (165). Локали: сняты «→», «+ » и эмодзи из строк.

## Осталось (по убыванию заметности)

1. **NSMeetingDetailsPage (2975 строк) и ChatPage (2354)** — прошли только
   скриптом. Структура «карточки в карточках», плотность, локальные
   заголовки — нужен ручной проход, лучше с разбиением на компоненты.
2. **Стат-плитки «большое число + подпись + тонированная иконка»**
   (CompanyInfoPage, StatsPage) — типовой дефолт; заменить на строку
   показателей с хайрлайнами либо на таблицу.
3. **RegulationsPage** — по одному цвету на вид документов (синий/зелёный/…)
   — второй акцент. Кодировать вид текстом/иконкой, оставить один синий.
4. **Таблицы** (AuditLogPage, TasksListPage, AdminUsersPage) — привести к
   Carbon data table: заголовок 14/600 на `#e0e0e0`, строки 48px, зебра нет,
   hover `#e5e5e5`.
5. **Модальные окна** — все с `--shadow-overlay`, но скругления и отступы
   разные; нужен единый `Modal` в `ui.tsx`.
6. **Мобильный шелл** — сайдбар просто исчезает под 768px, гамбургера нет.
7. Хардкод «мин»/«ч» в `formatRelativeTime` на главной — вынести в локали.
8. `letterSpacing` в inline-стилях кое-где остался с отрицательными em —
   Plex не любит отрицательный трекинг; убрать при проходе по страницам.

## Правила для новых экранов

- Один контейнер — белая плитка с хайрлайном. Иерархия — сменой поверхности
  (`canvas` → `surface`), не тенью и не вложенностью.
- Заголовок страницы 32/300, разделы 16/600, текст 14/400. Никакого капса.
- Синий — только ссылки, primary-кнопка, фокус, активный пункт навигации.
- Статус = тег из `StatusBadge` + при необходимости 3px левая рейка.
- Иконки — SVG 16px, stroke 1.5; эмодзи нет.
- Кнопки в ряд ставить через `gap: 1` (Carbon button group), не через 8–12px.
- Пустое состояние — `EmptyState`: заголовок + что делать, без картинки.
